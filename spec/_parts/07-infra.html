۷.۲ نقشه و ردیابی زنده (Live Tracking)

  • جریان موقعیت: اپ متخصص هر ۵–۱۵ ثانیه (و در حالت حرکت با فاصله محور) موقعیت را با حداقل بایت ارسال می‌کند → Kafka → سرویس Location → Redis Geo + سری‌زمانی برای بازپخش مسیر.
  • نمایش به مشتری: مسیر، ETA پویا، نام/عکس متخصص، پلاک خودرو یا مدل موتور، دکمه تماس امن و چت. «اشتراک مسیر زنده» با یک پیوند امن برای اعضای خانواده (اختیاری).
  • حریم خصوصی متخصص: ثبت موقعیت فقط در بازه فعال سفارش (از پذیرش/حرکت تا پایان کار)، نمایش متناسب با مرحله سفارش (مثلاً پیش از حرکت، فقط ETA)، توقف صریح با دکمه و امکان حذف سرگذشت مسیر پس از دوره نگهداری.
  • مسیریابی: سرویس مسیریابی داخلی یا نقشه‌های بومی (نشان، بلد، Map.ir) با امکان انتخاب صریح؛ محاسبه ETA بر پایه ترافیک لحظه‌ای و وسیله (موتور/خودرو).
  • ضدتقلب موقعیت: تشخیص Mock Location، جهش‌های غیرممکن (سرعت باورنکردنی)، عدم مطابقت با WiFi/شبکه ثبت‌شده → پرچم ریسک.

۷.۴ Push Notification و اطلاع‌رسانی

  • کانال‌ها: Push (FCM/APNs + سرویس جایگزین بومی)، SMS (دو تأمین‌کننده برای تحمل خطا)، ایمیل، WhatsApp/Telegram برای فاکتور و رسید (اختیاری)، پیام درون‌برنامه‌ای.
  • سرویس Notification مستقل: قالب‌ها در CMS، اولویت‌بندی صف (ERO/معمولی)، ضداسپم (سقف روزانه، ساعات مجاز، ترجیحات کاربر)، زمان‌بندی بر پایه منطقه زمانی، پیگیری رویداد ارسال/تحویل/کلیک.
  • رویدادهای حیاتی (با اولویت بالا): پیشنهاد فوری سفارش، لغو سفارش، تغییر زمان، تخصیص مجدد، ورود متخصص به محله، اعلان امنیتی ورود جدید.
  • قاعده: هر رویداد مهم باید «مسیر جایگزین» داشته باشد؛ اگر Push نشد → SMS؛ اگر پیامک هم نرسید → تماس خودکار اپراتور برای سفارش‌های بالای سقف.

۷.۷ چرخه توسعه، کیفیت و استقرار

  • محیط‌ها: Dev → Staging (داده شبه‌واقعی) → Canary → Production؛ Feature Flag برای هر قابلیت هوشمند و Kill-Switch برای موتور قیمت، Dispatch، Fraud و AI Intake.
  • CI/CD: تست واحد > ۷۰٪ روی سرویس‌های مالی و Dispatch + تست یکپارچگی قرارداد رویداد (Contract Tests) + تست مهاجرت DB + اسکن امنیت (SAST/DAST/Dependency).
  • DR و پایداری: RPO ≤ ۵ دقیقه، RTO ≤ ۳۰ دقیقه؛ پشتیبان‌گیری روزانه + PITR؛ تمرین بازیابی فصلی؛ Multi-AZ برای سرویس‌های حیاتی.
  • تیم و مالکیت: هر سرویس مالک (CODEOWNERS) و شاخص SLO دارد؛ فرهنگ Post-mortem بدون سرزنش (Blameless) و بستن سهماهه اقدامات اصلاحی.
