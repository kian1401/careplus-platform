۹فهرست APIها و رویدادهای رویدادمحور

سبک: REST نسخه‌دار (/v1) + JSON؛ احراز با Bearer Token؛ همه نوشتن‌ها Idempotency-Key؛ Real-time با WebSocket؛ فایل نهایی نمونه: achareh-plus/api/openapi-core.yaml.

۹.۱ قواعد قراردادی

موضوعقاعده
خطاها{"error":{"code":"ORDER_NOT_ASSIGNABLE","message_fa":"...","details":{...},"trace_id":"..."}} با کدهای معنایی (نه فقط HTTP Status)
صفحه‌بندیCursor-based: ?limit=20&cursor=... → {"items":[], "next_cursor":null}
نسخه‌بندیدر URL (/v1) + هدر اپ (X-App-Version) برای سیاست «کمترین نسخه پشتیبانی‌شده»
زمان پاسخp95 < ۳۰۰ms برای خواندن، < ۶۰۰ms برای نوشتن (بدون احتساب درگاه پرداخت)
محدودیت نرخبر پایه کاربر/دستگاه/IP + سهمیه سرویس؛ خطای 429 با هدر Retry-After
وب‌هوکامضای HMAC-SHA256 در X-Signature، تلاش مجدد نمایی تا ۲۴ ساعت، داشبورد رویداد برای پارتنر B2B
