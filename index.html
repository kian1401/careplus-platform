دموی تعاملی زنده: باز کردن کنسول دمو ←

سرویسا (Care+) بستهٔ کامل طراحی، مدل داده، API، نمونهٔ اولیه و MVP اجرایی — جانشین هوشمندتر پلتفرم «آچاره»

۶ ماژول + لایه هوشمندی AI ۲۲ آزمون سبز ۷۸ عملیات API ۷۶ جدول در سند ۵۰ وایرفریم چهار محور موفقیت: تطبیق · استانداردسازی · کیفیت پیش‌بینانه · تجربهٔ روان
این صفحه یک بستهٔ استاتیک روی GitHub Pages است — بدون سرور، بدون وابستگی به محیط توسعه؛ همهٔ اسناد و تصاویر از همین‌جا باز می‌شوند. برای دموی تعاملی، بخش «شروع سریع» را ببینید.

۱) شروع سریع بازبین دموی تعاملی

کنسول دمو: سناریوی ۹ گامی سفارش → Escrow → تخصیص موجی → تسویه، به‌همراه پنل هوشمندی (استانداردسازی، رتبه‌بندی مرحله ۲، کیفیت پیش‌بینانه، اقدام بعدی).

  • روی Render (آدرس ثابت): استقرار یک‌کلیکی Blueprint ← ⇒ پس از بیلد: https://careplus-mvp.onrender.com
  • اجرای محلی با دو دستور: 
    git clone https://github.com/kian1401/careplus-platform.git
cd careplus-platform/mvp
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
# مرورگر: http://localhost:8000

توضیح: لینک‌های «تونل موقت» قبلی با خواب‌رفتن محیط توسعه از کار می‌افتند؛ به همین دلیل مسیر پایدار = Render یا اجرای محلی.

۲) اسناد اصلی مطالعه و ارسال

  • سند جامع (۱۷ بخش، ۷۶ جدول، ۷ شکل) — کامل و خودبسنده
  • PDF سند جامع (۸۲ صفحه)
  • PDF تحلیل عمیق موتور تخصیص (۱۱ صفحه)
  • گزارش تحلیلی موتور تخصیص (HTML با نمودارها)
  • نمونهٔ اولیه و وایرفریم‌ها (۵۰ صفحه)

۳) فنی و واگذاری برای تیم توسعه

  • اسکیمای کامل پایگاه داده (PostgreSQL 16 + PostGIS)
  • واژه‌نامه داده (CSV، ۱۱۳ جدول)
  • فهرست API — ۷۸ عملیات + لایه هوشمندی
  • قرارداد OpenAPI
  • برآورد زمان و هزینه (RFP، ۵ برگه)
  • راهنمای کل بسته · راهنمای استقرار

۵) تصاویر کنسول دمو (لایه هوشمندی) تأیید بصری

یادداشت برای بازبین: دموی تعاملی زنده، روی سرور اجرا می‌شود و آدرس آن یا روی Render است یا در اجرای محلی؛ صفحهٔ حاضر (GitHub Pages) فقط اسناد، کد و تصاویر را بدون نیاز به سرور ارائه می‌دهد. آزمون‌ها: cd mvp && python3 -m pytest tests -q ⇒ ۲۲ آزمون سبز.
